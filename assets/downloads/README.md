# Downloads

## Already here — official Springer files

Downloaded from Springer's own CMS via the
[LNCS/Springer information for authors and editors](https://link.springer.com/series/558/information-for-authors-and-editors)
page. These are the current templates, not copies from another conference's site.

| File | What it is |
|---|---|
| `Springer-LaTeX-Template.zip` | LaTeX2e proceedings template — `llncs.cls`, `samplepaper.tex`, `splncs04.bst`, `llncsdoc.pdf` |
| `Springer-Word-Template.zip` | Word proceedings template — `splnproc2510.docm` (+ macOS variant), Quick Start and technical instructions |
| `Springer-License-to-Publish-Form.docx` | The consent-to-publish / licence form authors sign at camera-ready |
| `Springer-Instructions-for-Authors.pdf` | Springer's 10-page instructions for proceedings authors |

**Re-download these before the call for papers opens.** Springer revises the
templates (the Word one is versioned by date — `2510` is October 2025), and
authors who use a stale template get bounced at the production stage. Keep the
filenames identical and every link across the site keeps working.

Authors who prefer Overleaf can start from Springer's
[LNCS template](https://www.overleaf.com/latex/templates/springer-lecture-notes-in-computer-science/kzwwpvhwnvfj).
